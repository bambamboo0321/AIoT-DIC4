# Proposal

## Why

The actual V1 review identifies reproducibility gaps in lifecycle guards, session coordination, trial matching and agent scoring. V2 must resolve these documented issues without replacing V1 or inventing measurements.

## What Changes

- Operationalize questions and the scoped integration contribution (R1).
- Specify FSM guards/reset and quantity/correction semantics (R2-R3).
- Specify two-worker session coordination and query snapshot boundaries (R4, R7).
- Make E1-E5 prospective counts, matching, denominators and scoring reproducible (R5-R6, R8).
- Improve table typography and DOI discoverability (R9).
- Deliver V2, independent ZIP rebuild, actual latexdiff and review-to-change evidence.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `ieee-manuscript`: Add review-driven reproducibility, consistency and presentation obligations to the existing manuscript delivery capability.

## Impact

Adds `paper/v2-revised`, V2 deliverables, difference artifacts, prospective protocol details and validation/revision reports. V1 source and release artifacts remain byte-for-byte preserved. No private application deployment, participant data collection or credential-based Overleaf action is performed.
