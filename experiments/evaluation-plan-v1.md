# V1 prospective evaluation protocol

No E1-E5 data have been collected for this manuscript. This is a protocol outline, not a results file. Normative manuscript definitions are in V1 Section V; parameter choices must be frozen before test data collection.

| ID | Ground truth | Comparator | Recording requirements |
|---|---|---|---|
| E1 | Documented reference masses and independent balance | Calibrated scales against reference | Per-scale raw counts, load, placement, time, coefficient version, drift/settling |
| E2 | Observer/action schedule and independently weighed transfer | Weight delta, FSM, FSM + confirmation on identical traces | Lift/return times, candidate/final IDs, action label, prompts, undo and timeout |
| E3 | External scripted owner schedule for three users/two scales | Expected owner at event start | Session versions, acknowledgement, queued replay, switch time, unresolved events |
| E4 | Observer task log | Manual and semi-automatic within person | Order/training, full completion time, actions, omissions and corrections |
| E5 | At least 30 frozen synthetic fixture cases | Expected tool, value, provenance and permissions | Model/prompt/schema/workflow versions, repeated runs, final answer, errors |

Mass operating range, tolerances, sampling/window timing, trial counts, and final analysis details require a pre-execution freeze after hardware calibration. They are not represented as validated settings. Publication of raw health records or identifiable screenshots is excluded; obtain appropriate consent/review before participant work. Device and reference failure/exclusions must be retained in the execution log.
